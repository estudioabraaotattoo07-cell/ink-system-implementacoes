# domains/

Cada capacidade nova do projeto (Meu Site, ManyChat, Evolution API, N8N, IA
personalizada do cliente, e demais que surgirem) nasce aqui como seu próprio
módulo isolado — mesmo padrão de domínio já validado em
`inq-saas/lib/tenant/provisionamento/dominios/`.

Vazia de propósito nesta fundação (Bloco 4.7). Nenhum domínio é criado até
que a funcionalidade correspondente seja aprovada e auditada como seu
próprio bloco.
