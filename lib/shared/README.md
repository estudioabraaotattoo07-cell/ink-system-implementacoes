# shared/

Reservada exclusivamente para infraestrutura compartilhada entre domínios --
helpers, validações, logger, utilitários comuns. Nunca lógica de negócio de
um domínio específico.

Vazia de propósito nesta fundação (Bloco 4.7) -- existe pra que código
genuinamente cross-domain tenha um lugar certo desde o início, sem virar
código duplicado dentro de cada domínio.
